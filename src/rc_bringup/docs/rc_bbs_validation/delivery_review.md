# 独立交付审查：部分地图、质量门限与原始要求

这是只读源码与已有证据的审查，不代表新一轮实机成功，不修改生产参数。审查版本为启用 `unmapped_obstacle_filter`、严格 BBS 后空候选再进入部分重叠阶段的实现。后续若实现调整，应结合最新代码和新数据复核。

## 结论与优先修正

用户要求可靠定位并不过分。原来把所有环境回波的 65% 都要求对应纯赛场地图，是算法场景假设不合适。现在的地图支持过滤已处理这一问题，但真实未知初值全局恢复仍未完成。最值得优先修的是搜索阶段策略和实际结构证据的采样依赖，不是放弃多帧验证或把用户标注当固定初值。

### 1. 严格 BBS 非空就不做部分重叠搜索，存在恢复盲区

位置：`src/rc_bbs_localization/src/engine.cpp`，阶段循环中 `if(!seeds.empty()) break`，其后才逐候选 GICP。

某个严格粗候选可能只是体素偶合，GICP 或双侧结构检查最终失败；但只要粗候选非空，真实低重叠位姿就不再被枚举。这是逻辑上的召回盲区，不是质量门限问题。严格搜索超时或候选溢出时也不会进入低阈值阶段；这种情况按预算拒绝是正确的，但不能解释成地图中没有正确位姿。

即使严格候选质量通过，当前所谓搜索完整性也仅相对于严格阶段的分数门限。较低 BBS 命中、却同样具有高 ROI 覆盖/低残差的另一个合理位姿仍可能存在。因此不能把严格阶段通过称作“部分重叠模型下唯一的全局结果”。已有 `OBSTACLE_FILTER.md` 对这一限制做了说明。

建议：将严格和部分重叠定义为明确可配置的搜索模型，各自完整枚举并保持预算和候选上限；或在严格候选逐一精配准全部失败后，使用剩余预算执行部分重叠搜索。若需要在部分地图模型下宣布歧义已排除，应实际搜索该模型的候选集合；单纯严格优先不是同一件事。先保留失败时明确拒绝的行为，不能靠忽略未完成搜索来满足一秒目标。

### 2. 原始点结构比例门限有采样密度依赖

位置：`quality.cpp` 的 `nonground_fraction` 和 `consistent_structure_fraction`，及生产 YAML 的 8% / 5%。

两者的分母都是原始有效对应点，受地面反射密度、扫描累积重复次数和可见角度影响。相同可靠墙面，地面点更多即可使两项比例下降。增加独立地图结构体素数与结构跨度，比单纯原始点计数更能抑制重复点膨胀；然而这并不使比例门限成为场景无关的判据。

现有第二份实机局部结果：256 个双侧对应、13 个独立 0.30 米结构体素、约 3.48 米跨度、信息比约 0.00173，仍因目标侧非地面 6.39% < 8% 和双侧结构 4.02% < 5% 被拒绝。这里确实存在重复保守门限的可能，不能断言图中几何完全不匹配。另一方面第一份同位置扫描为 0 个双侧结构，说明不能只展示第二份就接受连续定位。

建议：单独进行比例门限消融，例如目标非地面 5%、双侧 3%，保留独立体素、跨度、退化、残差、歧义及连续新帧检查。消融只用于区分门限拒绝与结构不稳，不能直接替换为“定位成功”。长期更合适的是独立空间单元上的结构比例、法线方向分布和几何可观测性，而非积累回波数的比例。

12 个独立体素与 1 米跨度也是场景假设：一条直线或一面墙可以满足它们，因此必须同时保留信息矩阵/退化检查。两者不是完整六自由度约束的证明。

### 3. GICP 只按初始候选裁剪一次，会限制吸引域

位置：`Engine::registration_source()` 和 `Engine::refine()`。

GICP 输入按初始猜测与地图距离 0.75 米、XY ROI、法线差裁一次；之后 GICP 优化时不会重新纳入之前被裁掉的真实赛场点。初始粗位姿的偏差刚好使关键墙面落在距离或 ROI 门限外时，可能丢掉最需要的校正证据，留下近似地面而使局部优化停在错误区域。反过来，初始裁剪保留的临时障碍也不会在每轮重新剔除。最后的全有效扫描质量评估能阻止许多误接受，但不能挽回漏掉的结构。

建议：在总预算内用少量外循环重新按更新姿态生成支持点，再执行局部配准，检查输入集合及位姿是否稳定；始终相对原始 BBS 粗候选检查总位移/旋转修正，且每次最终验收仍用未删减的有效扫描统计。也可在已知可靠里程计传播的跟踪阶段和未知初值候选阶段使用不同的支持距离。不能通过裁剪后只评价同一小子集来得到虚假的 100% 覆盖率。

### 4. 信息矩阵的障碍物尺度问题已修复；统计名称仍应注意

当前部分地图模式只用真实对应点的 RMS 半径归一化旋转块。先前被排除的远处障碍仍会影响尺度的问题已修复，并有添加场外物体前后 `information_ratio` 一致的回归。

信息矩阵仍是目标法线构造的局部退化诊断，原始重复回波可影响各表面权重；它不是准确协方差，不能当实机误差或唯一性证明。单平面/单墙退化仍必须拒绝。

`coverage` 保留全部有效扫描为分母，符合原始用户要求；`roi_coverage` 明确分开报告，也有保留比例及范围内未匹配上限。`capped_all_mse_m2` 在过滤模式下现以 ROI 源点为分母并排除场外点，其名字容易被理解成全部扫描指标。建议以后另报 `capped_roi_mse_m2`，并保留真正全部有效点的 capped MSE 或明确标注其支持域，避免同名数据跨模式直接比较。

### 5. 地图 XY 支持并非通用赛场边界

当前 ROI 是地图 XY 投影邻域膨胀。本地图有密集地表采样，因此近似可用；只有稀疏墙面或缺测地面时，场内合法位置也可能被当作场外。用户给定真实边界多边形时可作为独立配置，但不应从当前车位生成只利于该位置的裁剪区域。25% ROI 保留比例是可调可见率先验，不是几何定位的必要定律。
