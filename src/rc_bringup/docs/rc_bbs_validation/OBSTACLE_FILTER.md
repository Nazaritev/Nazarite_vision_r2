# 纯赛场地图的未建图障碍物处理

用户确认 `1.pcd` 仅包含赛场，周围与临时障碍物不应成为定位地标。此前要求全部有效扫描至少 65% 对应地图，不适合这种局部静态地图。当前已加入障碍物抑制；实机未知初值的 1 秒定位目标仍未完成。

## 实现

- `unmapped_obstacle_filter: true`：地图 XY 点的投影及 `map_roi_margin_m: 0.35` 膨胀构成覆盖支持范围。该范围由地图生成，与用户标注位置无关。这里的地图有地表采样；这不是可直接用于只有稀疏墙面的任意地图的通用赛场多边形。
- GICP 输入先降采样，再根据本次候选姿态筛选覆盖范围、距静态地图不超过 `static_support_distance_m: 0.75` 的点，以及已知法线相容的对应。未经定位的原始扫描不能直接按地图坐标裁剪。
- 质量评估仍遍历全部有效源点，分别报告原始覆盖率、范围内覆盖率、范围外点数和范围内未匹配点数。范围外点不计为地图匹配失败；范围内至少保留 `min_roi_source_fraction: 0.25` 的源点，并最多允许 `max_unmapped_fraction: 0.65` 的未匹配/法线不相容点。没有把所有不匹配点删掉后宣称 100% 匹配。
- 保留至少 120 个双侧一致结构对应、至少 5% 的双侧结构占比，并增加至少 12 个独立的 0.30 米地图结构体素、至少 1 米结构跨度。信息矩阵只用实际对应点的半径尺度归一化，已排除的障碍不会继续影响退化判断。地图单侧非地面比例由 10% 调整为 8%，双侧结构、残差、收敛、多帧、歧义检查仍执行。
- BBS 先按原 0.90 命中阈值完成所有配置重力方向的搜索。如果严格搜索完整且没有任何候选，再使用显式部分重叠模式：最低绝对命中数为 `max(0.90 × (1−0.65) × N, 20)`。仍使用原始绝对体素命中目标和可采纳上界，没有使用未知位姿预先删点。两个阶段共用 1400 ms 预算。严格阶段已有候选时不进入低阈值阶段；因此搜索完整性及歧义判断始终相对于实际选择的阶段阈值，不是任意低分模式的绝对唯一性证明。
- CPU 补丁在评分前剪掉全局平移范围外的整棵子树；队列最大剩余上界低于最佳叶子时结束。保持同分处理与叶子边界检查。

这些规则是基于地图支持的离群点抑制，不能识别每个物体的真实身份。未建图物体如果恰好靠近地图表面且法线相容，仍可能进入候选，因此独立结构与多帧检查仍有必要。范围内可见比例、未匹配比例和结构比例均是可配置的场景假设，不是不可调整的物理定律。

## 当前证据

[用户辅助局部诊断及过滤前后图片](user_marked_pose/obstacle_filter/README.md) 使用同两份当前实机扫描。第二份扫描在过滤后地图范围内覆盖率为 81.9%，原始全扫描覆盖率为 55.7%；256 个双侧结构对应落在 13 个独立体素，跨度 3.48 米，但双侧结构占比为 4.02%，第一份扫描对应为 0。两份扫描共 16 次局部精配准均未通过全部门限。图中的起点来自用户标注约 `(3.7, 0.0)` 米、车头朝 `−Y`，不能当成 BBS 未知初值成功或精确位姿真值。

| 验证 | 结果 |
|---|---|
| 核心 GTest | 27 项通过，colcon 含测试包装器统计 28 项 |
| 地图派生合成 BBS→GICP 候选 | 6/6 通过，仍需新帧验证 |
| 同两份当前实机扫描的未知初值搜索 | 0/2；部分重叠搜索耗尽约 1400 ms |
| 新生产配置硬件观察 | 收到 568 帧扫描，验证位姿 0 条，主要为包含预处理的搜索超预算 |
| 合成 ROS 恢复场景 | 未知初值、错误初值、RViz 初值、输入中断恢复、重力拒绝、搜索中重设初值、地图重载/更新均通过 |

合成 ROS 冷启动首个验证位姿为 1.59 秒，最大位置误差 0.0281 米、旋转误差 0.00475 rad。它与硬件观察同时运行，属于本机单轮回归，不是稳定 P95，也不能替代实机误差。数据在 [global_search/](user_marked_pose/obstacle_filter/global_search/) 和 [live/](user_marked_pose/obstacle_filter/live/)。

低重叠阈值带来更多可行分支和不同模式，当前实机主要瓶颈仍是全局候选搜索及其歧义检查。局部配准图已经说明有接近的赛场对应；它与完全未知位置下独立找到并连续验证是不同验证阶段。没有写入固定初始位置，没有用用户标注缩小生产搜索范围，也没有发布未验证成功。

## 配置与复现

生产设置仍在 `config/reality/rc_localization.yaml`，launch 无需命令行参数。`unmapped_obstacle_filter: false` 恢复原质量和 GICP 输入路径；其他参数仍按 YAML 独立生效。

本轮离线候选回归配置为 `user_marked_pose/obstacle_filter/global_parameters.yaml`，用户标注附近的离线诊断为同目录 `parameters.yaml`。`localization_snapshot.yaml` 保存该次叠图的生产设置；后续修改生产 YAML 后，不应把新重跑数据与旧图混为同一轮结果。
